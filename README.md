# Torres Esmeralda e Safira · Gold Shopping Carazinho

Site do Gold Shopping (Av. Flores da Cunha, 1310 · Carazinho/RS), realização Secco Construtora.

- Página inicial com a escolha da torre (Esmeralda e Safira)
- Fachada que aproxima com a rolagem, plantas, 3D de cada apartamento e disponibilidade
- Mapa da região e contato direto pelo WhatsApp do comercial

Site estático: `index.html` + `img/` + scripts do 3D (`modelos.js`, `apto3d.js`, `esm3d.js`).
Publicado no Vercel; cada alteração enviada para a branch `main` entra no ar automaticamente.
